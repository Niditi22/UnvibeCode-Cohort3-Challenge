## Track 2 – My Proposal

### UnvibeCode GitHub Pull Request Assistant

My proposal is to integrate UnvibeCode with GitHub Pull Requests.

Whenever a developer opens or updates a pull request, UnvibeCode could automatically generate a code-impact report.

**Expected benefits:**
- Encourage developers to use UnvibeCode regularly.
- Show affected files, connected workflows and potential risks.
- Increase product visibility through branded GitHub comments.

**Implementation plan:**
1. Build a GitHub Action that triggers UnvibeCode analysis on pull requests.
2. Generate a concise report showing affected files and workflows.
3. Track repeated usage through analysis reruns and returning repositories.

*This is a proposed feature, not an implemented integration.*
