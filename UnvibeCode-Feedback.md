# My UnvibeCode Experience

## UnvibeCode Engineering Challenge 2026 – Cohort 3

I tested UnvibeCode on two GitHub projects, BankShield and BidSense.

The Business Workflow Map and Connected Code Map were the most useful features because they helped me understand how different files and features were connected without manually exploring the entire codebase.

One thing I found confusing was that the report was divided into multiple files, so it took some time to locate the complete analysis.

I also noticed that risk findings were disabled by server policy in my reviews. It would be helpful if the report explained this more clearly and distinguished verified findings from items that need manual investigation.

Overall, UnvibeCode was useful for understanding unfamiliar repositories and exploring their business workflows.
